অ্যাডমিন ড্যাশবোর্ড

শুধু তোমার Firebase অ্যাকাউন্ট দিয়ে লগইন করে লিংকগুলো আপডেট করো। প্রথমবার চালুর আগে Firebase সেটআপ লাগবে।

সেটআপ প্রয়োজন: firebase-config.js-এ সম্পূর্ণ Firebase Web App config বসাও, Firebase Authentication-এ Email/Password চালু করো এবং Firestore security rules বসাও। এই পেজে কোনো ডিফল্ট পাসওয়ার্ড রাখা নেই।
